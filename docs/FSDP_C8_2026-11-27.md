# C8 lima slice: transfer backbone rotasi Brain CT Seg

## Rancangan dan batas perbandingan

Dua arm berurutan menggunakan topology U-Net empat tahap downsampling, dua konvolusi per blok, skip decoder dan lima slice input. `plain4` memakai Conv2D/BatchNorm/ReLU; `c8` memakai ESCNN R2Conv/InnerBatchNorm/ReLU dengan grup C8 (delapan orientasi di bidang citra). Output akhir adalah field trivial satu kanal untuk logits mask. Tidak ada group pooling yang menghilangkan posisi piksel. Tiga keluaran decoder untuk deep supervision memakai bobot 1/0,3/0,15.

Default dua regular fields pada level awal menghasilkan 16/32/64/128/256 kanal skalar. Ini lebih ringkas daripada Brain asli yang memakai base_fields 32 (256 kanal awal). Kedalaman dan kanal skalar antara dua arm baru sama; jumlah parameter bebas dan constraint grup berbeda. Ini perbandingan struktur/group constraint, bukan parameter count yang identik atau salinan bobot Brain.

Lima slice native tetap direkonstruksi ke volume native, dengan GT ROI dan nol klik. Normalisasi z-score, shape-group sampler yang sudah diperbaiki, loss focal–Dice–boundary, split 53/10, LR 1e-4 dan seed sama. Maksimal 100 epoch/arm, patience 30. C8 adalah rotasi koordinat piksel; jika spacing XY anisotropik, rotasi piksel bukan rotasi fisik yang sama. Padding sampai kelipatan 16 (minimal 32 per sumbu) dan interpolasi membatasi equivariance di tepi; tidak ada klaim rotasi sempurna seluruh volume.

BatchNorm mengubah running statistics saat forward. Preflight backward mengambil snapshot lalu mengembalikan state awal sesudah pemeriksaan gradien; ini mencegah forward pemeriksaan menjadi update tersembunyi. ESCNN menyimpan cache filter pada mode eval. Wrapper checkpoint mengeluarkan cache transient tersebut dan mengembalikannya setelah strict load; parameter dan running statistics tetap dicatat.

## SAM-Med3D dan target 80%

Benchmark terbaik SAM affine memakai ROI ground truth dan lima klik oracle/sisi: volume Dice 49,983%, surface Dice @0,5 mm 78,568%, @1 mm 88,110%, median HD95 2,414 mm. Angka 88,110% tidak berarti volume Dice 80%. Run C8 mempelajari bobot 2D baru tanpa memuat bobot 3D SAM, tanpa point prompts. Foundation directory dipakai sebagai sumber cache dan benchmark metadata, bukan warm start C8. Gabungan SAM dan C8 memerlukan eksperimen teacher/prior/refinement terpisah, terutama memastikan tidak ada oracle masks/klik validasi sebagai input pada sistem yang diklaim otomatis.

Performa C8 belum tersedia. Sasaran volume Dice >=0,8 belum tercapai pada validasi cohort yang dilaporkan. Perbandingan dengan SAM bukan ablasi satu variabel. Mean patient Dice menjadi ukuran utama, dengan global Dice, surface Dice @0,5/1 mm dan median HD95 sebagai diagnostik tambahan. Test belum dibaca.

## Setup dan menjalankan

```bash
cd ~/raid/Clara/fsdp-train
git pull origin codex/exclude-mislabeled-train28
conda activate fsdp-med3d
bash scripts/setup_fsdp_c8.sh
ALLOW_GPU_SHARING=1 GPU_ID=auto bash scripts/launch_fsdp_c8_nohup.sh
tail -f logs/fsdp_c8/latest.log
```

Setup mempertahankan NumPy <2 sesuai requirements proyek, menginstal ESCNN 1.0.11 jika belum dapat diimpor, dan menggunakan backend numerik tanpa mensyaratkan Fortran/py3nj. Jika py3nj sudah terpasang, paket tetap dipakai dan versinya dicatat. Jangan berpindah environment/backend pada resume. Versi ESCNN, SciPy, lie-learn, pymanopt, autograd dan py3nj dicatat pada config C8. Jika paket sudah berfungsi, setup tidak melakukan instalasi ulang.

Launcher menuntut 48 GiB kosong dan menerapkan batas allocator PyTorch 24 GiB; ini bukan reservasi sistem. Semua artefak ditulis ke run baru. C8_BASE_FIELDS, C8_SLICE_BATCH, C8_EPOCHS, C8_PATIENCE dapat diatur sebelum launcher; dua arm menggunakan nilai yang sama. C8_BASE_FIELDS default 2, tidak disarankan langsung memakai 32 pada GPU bersama. Lokasi run: logs/fsdp_c8/latest_run.txt. Laporan akhir: comparison.json, dengan metrik per arm dan delta_c8_vs_plain4. Preflight menyimpan total parameter masing-masing arm.

Empat tes CPU dengan ESCNN nyata lulus: backward dan bentuk native, strict checkpoint eval roundtrip, respons blok encoder terhadap rotasi 90 derajat, serta pengembalian state BatchNorm pada control. Pengujian memakai model kecil base_fields=1. Konstruksi dan forward/backward bentuk native sesungguhnya di DGX tetap diperiksa oleh preflight sebelum optimizer update. Training dan reproduksi checkpoint CT penuh belum dilakukan dari sesi ini.
